# TaskCard

数据处理流程中单个 Task 的状态卡片。

## 结构

```
┌─────────────────────┐
│  导入销售订单         │  ← task.title, 14px w600
│  达标                │  ← task.status.label, 12px, status.color
└─────────────────────┘
```

## 视觉规范

| 属性 | 值 | 说明 |
|------|----|------|
| 背景 | `Colors.white` | 白色卡片 |
| 圆角 | `12px` | 圆角矩形 |
| 边框 | `Color(status.color).withValues(alpha: 0.2)` | 状态色 20% 不透明度 |
| 阴影 | `black 4%`、`blur 4`、`y 1` | 极淡投影 |
| 内边距 | `H16 V12` | 水平 16、垂直 12 |
| 最小宽度 | `130` | 保证卡片不因文字过少而缩窄 |

## 信息层级 1

1. **标题** — `task.title`，14px w600，黑色。展示任务名称如"导入销售订单"
2. **状态标签** — `task.status.label`，12px，状态色。如"达标"(green-600)、"进行中"(blue-600)

## 状态驱动配色

颜色不自定义，完全由 `TaskStatus.color` 决定。新增状态无需改卡片代码：

| 状态 | 文字色 | 边框（20% 不透明度） |
|------|--------|-------------------|
| pending | `#9CA3AF` | `#9CA3AF` 20% |
| inProgress | `#2563EB` | `#2563EB` 20% |
| completed | `#16A34A` | `#16A34A` 20% |
| failed | `#DC2626` | `#DC2626` 20% |
| rejected | `#D97706` | `#D97706` 20% |
| cancelled | `#6B7280` | `#6B7280` 20% |
