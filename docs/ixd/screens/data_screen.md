# DataScreen

## 定位

数据页面。两个核心概念同时展示：**Pipeline**（数据流程）和 **Dataset**（数据集）。

```
┌────────────────────────────────────────────┐
│  数据流程                                    │
│  [导入] → [清洗] → [合并] → [计算] → [生成]  │
│  达标     达标     进行中    进行中    就绪   │
├────────────────────────────────────────────┤
│  数据集                                     │
│  ┌ sales_orders ┐    ┌ unified_customer ┐  │
│  │ 已达标       │    │ 就绪             │  │
│  └─────────────┘    └──────────────────┘  │
│  ┌ order_clean  ┐    ┌ customer_rfm     ┐  │
│  │ 已达标       │    │ 进行中           │  │
│  └─────────────┘    └──────────────────┘  │
└────────────────────────────────────────────┘
```

Pipeline 展示执行流程和状态，Dataset 展示数据产物及其就绪状态。

Dataset 引用 Schema 作为结构定义，但 Schema 本身无状态——它是 Contract/Catalog 的纯契约。状态是 Dataset 的属性，表示该数据集当前是否已就绪。
