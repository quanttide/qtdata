# DataScreen

## 定位

数据页面。两个核心概念同时展示：**Pipeline**（数据流程）和 **Schema**（数据模型），左右或上下布局。

```
┌────────────────────────────────────────────┐
│  数据流程                                    │
│  [导入] → [清洗] → [合并] → [计算] → [生成]  │
│  达标     达标     进行中    进行中    就绪   │
├────────────────────────────────────────────┤
│  数据模型                                    │
│  ┌ sales_orders ┐    ┌ unified_customer ┐  │
│  │ 已达标       │    │ 就绪             │  │
│  └─────────────┘    └──────────────────┘  │
│  ┌ order_clean  ┐    ┌ customer_rfm     ┐  │
│  │ 已达标       │    │ 进行中           │  │
│  └─────────────┘    └──────────────────┘  │
└────────────────────────────────────────────┘
```

Pipeline 展示执行流程和状态，Schema 展示数据资产的产物和就绪状态。两者通过 Task 的输入输出关联，但在页面上平级展示。
