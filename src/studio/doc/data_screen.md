# 数据页面（DataScreen）

## 页面定位

展示数据处理流程（上段）及数据集（下段）。流程步骤来自 `Pipeline`，数据集作为独立资产列表展示。两个资源通过步骤与数据集名称/业务含义松散关联，UI 层面不做一一对齐匹配。

## 布局

```
┌──────────────────────────────────────────────────────┐
│  AppBar: 数据流程                                    │
├──────────────────────────────────────────────────────┤
│  ┌ 流程区域（水平滚动，左对齐）──────────────────┐   │
│  │  [卡片] → [卡片] → [卡片] → [卡片] → [卡片]   │   │
│  │  步骤名  步骤名  步骤名  步骤名  步骤名         │   │
│  │  ● 状态  ● 状态  ● 状态  ● 状态  ● 状态       │   │
│  └─────────────────────────────────────────────────┘   │
│                                                       │
│  数据集                                                │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                         │
│  │卡片│ │卡片│ │卡片│ │卡片│                         │
│  └────┘ └────┘ └────┘ └────┘                         │
│  (Wrap 布局，自动折行)                                 │
└──────────────────────────────────────────────────────┘
```

### 上段：流程区域（PipelinePanel）

- 步骤卡片水平排列，超出时横向滚动
- 卡片左对齐（不居中），箭头指引顺序
- 卡片高度由内容决定，不撑满页面
- 背景无独立容器

#### 任务卡片（TaskCard）

| 属性 | 值 |
|------|-----|
| 最小宽度 | 220px |
| 内边距 | 水平 20px，垂直 16px |
| 边框 | 2px，颜色跟随状态色（30% 透明度，悬停时 100%） |
| 圆角 | 12px |
| 阴影 | 微弱（黑色 4% 透明度） |
| 内容 | 步骤标题（15px，加粗）+ 状态指示圆点（8px）+ 状态标签 |
| 悬停 | 鼠标指针变为手型，边框色加深至 100% |

#### 状态定义

| 状态 | 圆点颜色 | 中文标签 |
|------|---------|---------|
| `pending` | 灰色 | 就绪 |
| `inProgress` | 蓝色 | 进行中 |
| `completed` | 绿色 | 完成 |
| `failed` | 红色 | 异常 |
| `rejected` | 橙色 | 驳回 |
| `cancelled` | 灰色 | 取消 |

### 下段：数据集区域（DatasetPanel）

- 上方左对齐标题"数据集"
- 卡片使用 Wrap 布局，自动折行
- 数据集为空时整段隐藏

#### 数据集卡片（DatasetCard）

| 属性 | 值 |
|------|-----|
| 最小宽度 | 180px |
| 内边距 | 水平 16px，垂直 12px |
| 边框 | 1px，固定灰色 |
| 圆角 | 10px |
| 阴影 | 微弱（黑色 3% 透明度） |
| 内容 | 数据集标题（13px，加粗）+ 状态指示圆点（6px）+ 状态标签 |

### 导航

页面实例化由调用方传入 `PipelineRepository` 和 `datasets` 列表，通过 `BlocProvider` 创建 `PipelineBloc` 管理流程加载状态。

- 加载中：居中转圈
- 加载失败：错误信息 + 重试（未来扩展）
- 加载成功：渲染流程 + 数据集

## 边界情况

| 场景 | 行为 |
|------|------|
| 流程 tasks 为空 | PipelinePanel 不渲染 |
| 数据集为空 | DatasetPanel 整段隐藏 |
| 数据集多于流程步骤 | Wrap 自动换行 |
| 长流程（>6 步） | 水平滚动 |
| 窄窗口 | 水平滚动流程行，Wrap 自动适应 |

## 状态同步说明

当前 mock 数据中流程步骤与数据集之间的状态没有强一致性约束。两步之间的状态映射由调用方控制：

- 已完成步骤对应的数据集 → `DatasetStatus.ready`
- 执行中步骤对应的数据集 → `DatasetStatus.pending`（缺 processing 态，待 0.3.0）
- 未开始步骤 → 无对应数据集
