# 项目详情（ProjectDetailScreen）

## 定位

单项目详情页（`project.html`）。通过 URL 参数 `?name=<项目名>` 定位项目，展示全流程进度矩阵、完整数据蓝图、交付时间线与资料下载。从首页点击项目卡片进入。

## 区块说明

### 标题行

- 返回按钮：回到首页（`index.html`）
- 项目名称 / 状态徽章 / 阶段标签：来自 `projects[name]`
- 客户与创建时间：`client` / `created`
- 导出按钮：原型交互，点击弹出 toast「📄 报告已导出」

### 全流程进度总览（二维网格）

由 `data.matrix` 渲染：

- 行（维度）：`rows` — 📋 项目 / 📊 数据 / 💼 商务
- 列（阶段）：`columns` — 调研 / 谈判 / 实施 / 验收 / 复盘，各带阶段状态
- 单元格：`cells[key]`（key = `行key_列key`），展示交付物名称与状态（已完成 / 进行中 / 待启动）

### 完整数据蓝图

- **处理流程**：`blueprint.steps`，编号步骤列表
- **异常处理预案**：`blueprint.exceptions`，`label`（场景）+ `strategy`（策略）

### 交付时间线

由 `data.phases` 渲染，每个阶段：

- 阶段名 + 状态（已完成 / 进行中 / 待启动）+ 交付物数量
- 交付物条目：名称、描述；`hasDoc: true` 时显示「查看资料」入口

### 资料弹窗（docModal）

- 「查看资料」→ 打开弹窗，按交付物名称关键字（Assignor / Assignee / Owner / 标准化 / 合同）匹配预置文件列表
- 「下载」→ 原型交互，弹出 toast 提示
- 点击弹窗遮罩或 ✕ 关闭

## 交互

- 入口：首页卡片点击 → `project.html?name=<项目名>`
- URL 参数缺失或项目不存在：toast 提示「项目数据不存在」并 1.2s 后跳回 `index.html`
- 页面标题（`document.title`）随项目名更新

## 数据与文件

| 文件 | 作用 |
|------|------|
| `project.html` | 页面结构与静态区块 |
| `css/style.css` | 全部样式（与首页共享） |
| `js/data.js` | 项目数据源 `projects`（与首页共享） |
| `js/common.js` | toast / 资料弹窗公共交互（与首页共享） |
| `js/project.js` | 本页渲染逻辑：`renderMatrix` / `showTimeline` / `showDoc` |
| `index.html` | 首页入口（见 `index.md`） |

## 维护

- 新增项目：在 `js/data.js` 的 `projects` 中按相同结构添加条目，包含 `matrix` / `blueprint` / `phases`
- 调整资料文件列表：`js/project.js` 的 `showDoc` 中按名称关键字分支
- 修改网格样式：`css/style.css` 中 `.grid-matrix` 及子类
