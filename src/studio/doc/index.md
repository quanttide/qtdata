# 我的项目（首页 / IndexScreen）

## 定位

项目总览页（`index.html`）。展示当前所有数据项目的进度总览，支持按状态筛选，点击项目卡片进入项目详情页（`project.html`）。

- 右侧主区域：标题、统计卡片、筛选按钮、项目卡片列表

## 区块说明

### 统计卡片（stat-card）

| 卡片 | 说明 |
|------|------|
| 全部项目 | 项目总数 |
| 进行中 | `status` 为「进行中」的项目数 |
| 已完成 | `status` 为「已完成」的项目数 |
| 待启动 | `status` 为「待启动」的项目数 |

### 项目卡片（project-card）

每张卡片展示一个项目：

- **名称**：`projects[key].name`
- **状态徽章**：进行中 / 已完成 / 待启动（`status-badge`）
- **阶段标签**：调研 / 谈判 / 实施 / 验收 / 复盘（`phase-tag`）
- **交付物仪表**：按 `deliverables[].status` 统计 已完成 / 进行中 / 待启动 数量
- **交付完成度**：`已完成数 / 总数` 百分比进度条
- **确认收入**：`contractAmount × (已完成数 / 总数)`，单位万元

## 交互

- 点击统计卡片或筛选按钮：按状态过滤卡片列表，同步更新「N 个项目」计数
- 点击项目卡片：跳转 `project.html?name=<项目名>`（URL 编码）
- 侧边栏「我的项目」图标 / Logo：返回本页

## 数据与文件

| 文件 | 作用 |
|------|------|
| `index.html` | 页面结构与静态区块 |
| `css/style.css` | 全部样式（与详情页共享） |
| `js/data.js` | 项目数据源 `projects`（与详情页共享） |
| `js/common.js` | toast 提示等公共交互（与详情页共享） |
| `js/dashboard.js` | 本页渲染逻辑：`renderProjects` / `filterProjects` / `countDeliverableStatus` |
| `project.html` | 项目卡片点击后的目标页（见 `project.md`） |

## 维护

- 新增项目：在 `js/data.js` 的 `projects` 中按相同结构添加条目
- 统计卡片数字在 DOM 中为静态占位，实际计数由 `renderProjects()` 初始化后经 `filterProjects('all', ...)` 刷新
- 修改卡片样式：`css/style.css` 中 `.project-card` 及子类
